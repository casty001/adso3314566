Propiedades de Background

Visualización de Fondo
1. color

Define el color de base. Útil mientras carga la imagen o como capa final.

2. image

Coloca una imagen o un degradado (linear-gradient).

3. repeat

Valores: repeat, no-repeat, repeat-x, repeat-y.

4. position

Ubica la imagen: top, center, bottom, left, right o px/%.

5. size

cover (llena todo), contain (se ve completa), o tamaños fijos.
